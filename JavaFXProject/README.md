# Virtual Dictionary

JavaFX-приложение-словарь с разделением на модель (`Dictionary`), контроллер
(`DictionaryController`) и представление (`DictionaryView`). В словаре есть
несколько примеров слов на английском языке.

## Требования

- JDK 21
- Maven 3.9 или новее

## Запуск

Из папки `JavaFXProject` выполните:

```shell
mvn clean javafx:run
```

В IntelliJ IDEA откройте `pom.xml` как Maven-проект, дождитесь загрузки зависимостей и запустите цель `javafx:run` в окне Maven. Также можно запустить класс `DictionaryView`.

Введите слово и нажмите **Search** или Enter. Поиск не зависит от регистра;
пустой ввод и отсутствующее слово показывают понятное сообщение.
